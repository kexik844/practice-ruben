# Демонстрация преподавателю

1. Запустить backend и frontend по корневому README. Открыть каталог при ширине 1280 px.
2. Выбрать «Ремонт техники», доступность, цену 1000–2500 ₽, сортировку по убыванию, затем поиск «Ремонт». В DevTools → Network показать объединённые query-параметры.
3. Сбросить фильтры, перейти на вторую страницу. Открыть карточку услуги, обновить браузер. Открыть `/services/999999` и показать обработку 404.
4. Оформить заявку с прошедшей датой, показать 400 и сообщение возле поля. Исправить дату на будущую и показать номер заявки и ответ 201.
5. Войти на `/manage` под администратором. Создать новую услугу, изменить цену, категорию, доступность. Удалить новую услугу без связанных заявок: сначала отменить подтверждение, затем подтвердить. Показать запросы POST, GET, PATCH, DELETE.
6. Показать отказ доступа без прав. Остановить Django, показать ошибку загрузки, запустить сервер и нажать «Повторить загрузку». Сценарий 500 отдельно воспроизводится в Playwright.
7. Включить мобильный режим 390 px. Добавить услугу в избранное и обновить страницу.
8. Показать структуру backend/frontend, исходники JSX, тесты и историю трёх коммитов.

Скриншоты реального API формируются Playwright в `docs/screenshots/`.
