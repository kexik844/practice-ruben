# React + JSX

Клиентская часть каталога услуг. Компоненты и страницы написаны на JSX, хуки и HTTP-клиент — на JavaScript.

Запуск из папки frontend при работающем Django:

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Сборка: `npm run build`. Сквозная проверка: `npm run test:e2e` после подготовки учебной базы и переменных администратора. Подробные команды и описание маршрутов — в [корневом README](../README.md).
